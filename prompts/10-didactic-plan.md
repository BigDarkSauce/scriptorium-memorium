# Plan a 3D demo before building it

The app sends this before it authors a scene (stage 5 of the pipeline). The plan is short (about 1.5k tokens): the demo's question, the kind of knowledge, the levels of its multiscale scene graph, Jared Owen's sequence (curiosity → orientation → decomposition → inspection → mechanism → intuition → reconstruction → understanding, recursive inside a beat) with one operation of the visual grammar and one camera mode per beat, an analogy with its limit, and the comprehension check. Operations are named, never described: the app already knows how to explode, section, compare, zoom, track and so on. `node tools/verify-chain.mjs plan.json` checks a plan; the built-in models' own plans are in `../js/dio/plans.js` (`node tools/verify-chain.mjs --builtins`).

```text
Plan a 3D explanatory demo BEFORE it is built (no scene yet: only the plan).
WHAT IT MUST SHOW: <what the diorama must show>
THE QUESTION IT MUST ANSWER: <the question the demo answers>
CONTEXT: <the study step it illustrates>
PLAN (a black-and-white storyboard; short: ≤ 8 beats, ≤ 20 words a field):
{"question":"the one question the demo answers","knowledgeKind":["structural|internal|causal|scale|history|pathology|movement|perspective", …] (primary first),
 "levels":["Organism","Organ","Tissue","Cell","Molecule"] or ["System","Subsystem","Part","Mechanism"] (only the levels it visits; or [{"name":"Vessel","at":"actor"}]),
 "sequence":[{"stage":"curiosity|orientation|decomposition|inspection|mechanism|intuition|reconstruction|understanding","technique":"<one OPERATION>","cameraMode":"global|object|component|mechanism|frame","purpose":"why this beat","answers":"the sub-question it settles","opens":"the question it raises","on":["actor"],"lesson":<index of the lesson that plays it>,"motion":{"explanatory":["what moves to explain"],"background":["what only moves to make it alive"]},"sub":[…the same, recursively, inside one beat]}],
 "analogy":{"familiar":"…","maps":"what corresponds to what","limit":"where it breaks"},
 "comprehensionCheck":{"explainBack":"what the learner must explain in their own words","misconceptionToAvoid":"the wrong answer to rule out","answer":"the correct explanation in 1–2 sentences"}}
OPERATIONS (by name only; never describe how to animate them): establish = the whole object or environment, still: the establishing shot [any]; explode = parts move apart along an axis with guides to their seats, numbered, then reassemble [structural]; assemble = parts arrive in order (assembly or history), each with its caption [history, structural]; inspect = close-up of each component in turn, then back to the whole [internal, structural]; section = a cut plane swept in, capped in ink, the whole kept in view [internal]; peel = outer layers ghosted, lifted or clipped one at a time [internal, structural]; isolate = everything but the acting subsystem dimmed [any]; chain = a highlight travels the actors in the order of cause, numbered [causal, movement]; zoom = one continuous zoom through stations named after levels, a landmark kept as a ghost [scale, internal]; scaleTo = a lineup at one size, then each at its true relative size [scale]; compare = two states side by side (or split) through one camera [pathology, causal]; progression = normal → initiating event → structural change → impairment → consequence → intervention [pathology, history, causal]; track = follow one particle along its path (a ride on a rail) [movement, perspective]; pov = outside → follow → inside: the camera takes the subject's frame of reference [perspective, movement]; analogy = a familiar thing that works the same way, with where it stops working [any]; answer = back to the whole; the opening question answered in one sentence [any].
STAGES in Owen order (skip what the subject does not need; repeat a stage for several beats; recurse with "sub"): curiosity = a question that opens a gap; orientation = the whole first (establishing); decomposition = functional parts; inspection = one part's inside, located in the whole; mechanism = the causal process, motion with meaning; intuition = analogy or scale comparison; reconstruction = back to the whole working; understanding = the answer.
RULES: choose each technique by the kind of knowledge (structure → explode; inside → section/inspect; cause → chain; scale → zoom/scaleTo; history → assemble; change/disease → compare/progression; movement → track; viewpoint → pov); an inside (section, peel, inspect, zoom) only after a global or object beat; every mechanism beat says which motion explains and which is background; the analogy names its limit.
Return ONLY the JSON plan.
```
